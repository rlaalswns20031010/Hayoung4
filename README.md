# Hayoung4

Hayoung4는 기존 하영툴에서 포크되어 구조와 사용자 인터페이스를 재정리한 브라우저 확장 프로그램입니다.

잡코리아와 게임잡의 채용공고, 회사 페이지 표시 정보, 사용자가 불러온 공고 기록을 한 화면에서 확인할 수 있도록 돕습니다. 게임잡에서는 공공데이터포털에서 제공하는 국민연금 가입 사업장 자료를 함께 비교할 수 있습니다.

표시되는 정보는 각 출처의 수집 시점과 집계 기준에 따라 실제 현황과 다를 수 있으므로 참고 자료로 사용해주세요.

## 주요 기능

- 잡코리아·게임잡 채용공고와 회사 정보 확인
- 페이지 단위 과거 공고 호출 및 제목 검색
- 사용자가 불러온 공고 기록의 로컬 저장
- 게임잡 페이지 표시 사원수와 국민연금 사업장 가입자 현황 비교
- 회사·문구·공고 숨기기와 집중 검색
- 간편 모드와 일반 모드

## 설치

1. GitHub Releases에서 최신 ZIP 파일을 받습니다.
2. ZIP 파일의 압축을 풉니다.
3. Chrome은 `chrome://extensions`, Brave는 `brave://extensions`를 엽니다.
4. 개발자 모드를 켭니다.
5. `압축해제된 확장 프로그램을 로드합니다`를 선택합니다.
6. 압축을 푼 폴더를 지정합니다.

기존 사용자는 새 파일로 교체한 뒤 확장 프로그램 관리 화면에서 새로고침하면 됩니다.

## 데이터 안내

- 채용 사이트에서 표시되는 수치와 공고 목록은 사이트의 현재 응답을 기준으로 합니다.
- 공고 개수와 실제로 확인 가능한 공고 링크 수가 다를 수 있습니다.
- 국민연금 자료의 가입자 수는 직원 수와 같은 의미가 아닙니다.
- 국민연금 자료는 신고 시점과 공개 기준에 따라 최근 변화가 즉시 반영되지 않을 수 있습니다.
- 소규모 사업장은 공개 자료에서 검색되지 않을 수 있습니다.
- 확장 프로그램에서 만든 설정과 기록은 사용자의 브라우저 저장소에 보관됩니다.
